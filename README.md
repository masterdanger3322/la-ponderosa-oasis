# La Ponderosa Oasis

I want to create a professional website for La Ponderosa, a hotel and tourist resort offering cabins, hotel rooms, and a camping area, located in Fortín de Santa Rosa, Canelones Department, Uruguay, just a few minutes from the beach.

Tech Stack

React

TypeScript

Tailwind CSS

The website should be 100% responsive, mobile-first, with smooth scroll animations (fade-in, slide-up) that feel elegant and subtle, not overdone. It should prioritize fast loading times and optimized images.

Brand Identity

Color Palette

Forest Green (#2E5E3B) as the primary color.

Sand (#E8D6B0) for warm backgrounds and secondary elements.

White for clean spacing.

Water Blue (#6FAFC9) as an accent color for buttons, links, and interactive elements.

Typography

Playfair Display for titles and headings (elegant and distinctive).

Inter for body text (modern and highly readable).

Visual Style

The design should evoke nature, relaxation, and family warmth.

Avoid a corporate urban hotel aesthetic.

It should communicate:

Large green spaces

Peace and tranquility

Proximity to the beach

A welcoming atmosphere for families and vacationers

Target Audience

Families with children

Couples

Campers

Groups of friends

Weekend travelers

Summer vacation guests

Small private events (birthdays, family gatherings)

WEBSITE STRUCTURE

1. Hero Section (Full Screen)

Full-screen background image or video showcasing the resort, nature, pool, and green spaces.

Main headline:

Relax surrounded by nature just minutes from the beach

Subtitle:

Hotel, cabins, and camping in Fortín de Santa Rosa, Canelones.

Include two prominent CTA buttons:

Reserve Now

WhatsApp

The WhatsApp button should open a pre-filled message using a wa.me link.

Also include a floating WhatsApp button fixed in the bottom-right corner that remains visible throughout the site.

2. About Us

Include:

Brief history of the resort.

Mission and philosophy centered on nature, relaxation, and family experiences.

Highlight 3–4 differentiators such as:

Extensive green areas

Unique combination of hotel + cabins + camping

Swimming pool

Close proximity to the beach

Include icons or highlight numbers such as:

X hectares of green space

X minutes from the beach

Create three modern accommodation cards with subtle hover effects.

Each accommodation type should have its own image gallery.

Embedded interactive Google Map.

Modern gallery with lightbox.

Google Reviews section.

Functional contact form.

Fully responsive mobile-first layout.

Smooth scroll animations.

Sticky navigation with anchor links to every section.

DESIGN DIFFERENTIATORS

Large, immersive full-width photography wherever possible.

Modern visual design that avoids looking like an outdated hotel website.

Accommodation cards with soft shadows and elegant hover effects.

Optimized image loading and fast performance.

Architect the CTA and booking components so an online reservation engine can be integrated later without redesigning the site (do not implement booking functionality yet, only prepare the structure).
